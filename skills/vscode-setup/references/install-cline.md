# Install Cline Extension Guide

## What is Cline?

Cline is your AI coding assistant built right into VS Code. Think of it like having a patient, knowledgeable programming teacher sitting next to you — they'll guide you through everything, explain concepts, and help you build your app step by step.

## Step 1: Open Extensions View

In VS Code:
1. Click the Extensions icon on the left sidebar (looks like 4 squares)
2. Or press `Ctrl+Shift+X` on your keyboard

## Step 2: Search for Cline

In the Extensions search box at the top, type: `Cline`

Look for the extension called **"Cline"** by **Saoud Rizwan**.

## Step 3: Install Cline

1. Click the "Install" button next to Cline
2. Wait for the installation to complete (you'll see a progress indicator)
3. If prompted, click "Reload Required" to restart VS Code

## Step 4: Open Cline

After installing:
1. Click the Cline icon in the sidebar (looks like a little chat bubble)
2. Or press `Ctrl+Shift+P` to open the command palette
3. Type "Cline" and select the Cline command

## Step 5: Verify Installation

You should see the Cline chat interface. If you see a chat box where you can type messages, congratulations — Cline is installed!

## Step 6: Try Cline

Type a simple message to test:
```
Hello! Can you help me build an app?
```

If Cline responds, everything is working perfectly!

## Troubleshooting

### Cline won't install
- Make sure you have the latest version of VS Code
- Check your internet connection
- Try restarting VS Code and trying again

### Cline shows as disconnected
- Check your internet connection
- Make sure your API key is configured in `.env`
- Try reloading VS Code (`Ctrl+Shift+P` → "Developer: Reload Window")

### Cline doesn't respond
- Make sure you have an API key configured
- Check that you have internet access
- Try asking a simpler question

# Product Context

## Product Vision

LearnPlayDevAI is a "starter workspace" template that enables completely non-technical users to begin building apps with AI guidance. Users pull this template from a public GitHub repo and immediately have everything configured to start vibe-coding their app idea with Cline.

## User Journey

1. User visits GitHub page for LearnPlayDevAI
2. User installs VS Code + Cline extension
3. User requests free API key from jan@learnplay.co.za
4. User sets up their environment (WSL on Windows, or native Linux/Mac)
5. User creates a project folder and pulls the template
6. User sets up GitHub account and connects their repo
7. User tells Cline: "I want to create an app that does X"
8. Cline guides them through everything from there

## Enterprise Positioning

This is the entry point to the LearnPlay ecosystem:
- Free API keys for starter users
- Upsell path to full LearnPlay platform
- Community building through accessible developer onboarding
